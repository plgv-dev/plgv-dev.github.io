# PRINCE LINK GLOBAL VENTURES — GitHub Pages

Official free website package for **PRINCE LINK GLOBAL VENTURES**.

## Publish

Repository: `plgv-dev.github.io`

Target website: `https://plgv-dev.github.io/`

1. Open the repository on GitHub.
2. Upload all files in this folder to the repository root (not the folder itself).
3. Commit the changes to the default branch.
4. In **Settings → Pages**, under **Build and deployment**, choose **Deploy from a branch**.
5. Select the default branch and **/(root)**, then save.
6. Wait for GitHub Pages to publish the site.
